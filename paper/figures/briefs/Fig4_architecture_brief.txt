INSET BOX — CBAM BLOCK  (dashed border, below or beside main flow)
═══════════════════════════════════════════════════════════════════
Same visual treatment as the "Residual Block (RB)" inset in the
original figure: dashed rectangle, white/light background inside.

Label at top: "CBAM Attention Block"

Inside, show two sequential sub-modules side by side with an arrow:

  ┌──────────────────────────┐    ┌──────────────────────────┐
  │   Channel Attention      │ →  │   Spatial Attention      │
  │  GAP ──┐                 │    │  Avg pool (ch-wise) ──┐  │
  │  GMP ──┴─► MLP ─► σ ─► ⊗│    │  Max pool (ch-wise) ──┴─►│
  │           (64→8→64)      │    │  Conv 7×7×7 ─► σ ─► ⊗   │
  └──────────────────────────┘    └──────────────────────────┘

MLP = two 1×1 Conv layers with reduction ratio 8 (64 → 8 → 64).
σ = sigmoid gate multiplied element-wise (⊗) with the feature map.
GAP = global average pool; GMP = global max pool.
Keep this inset compact — icons/small boxes only, no equations needed.

CAPTION DRAFT
═══════════════════════════════════════════════════════════════════
"Network architecture shared by CBAM-DNS (r = 1) and CBAM-SupRes
(r = 2). The phase-contrast stream (PC-MRA, magnitude, speed) and
the velocity stream (Vx, Vy, Vz) are each encoded by two
convolutional layers, concatenated, and refined by eight low-
resolution residual blocks. A CBAM attention module applies
sequential channel re-weighting (GAP + GMP, MLP with reduction 8)
and spatial re-weighting (7×7×7 convolution) before trilinear
upsampling by factor r and four high-resolution residual blocks.
Three convolutional heads emit the reconstructed velocity components."
